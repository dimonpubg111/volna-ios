# Как выпустить VOLNA в App Store

Для личной установки через AltServer этот процесс не требуется. Для обычной публичной публикации нужен аккаунт владельца в Apple Developer Program и одобрение Apple. Действующие условия проверены 30 октября 2026 года.

1. **Подтвердить возможность использовать контент.** Для трансляции сторонних каналов и размещения стороннего контента Apple требует разрешённое использование. Открытая ссылка на GitHub не является документом о лицензии. Apple может попросить подтверждение прав или условий, позволяющих такое использование. Нужны разрешения владельцев/поставщика для выбранного публичного сервиса либо другой каталог с явно разрешённым распространением. Одно лишь включение рекламы в потоке не подтверждает права разработчика VOLNA. [Правила 5.2–5.2.3](https://developer.apple.com/app-store/review/guidelines/#intellectual-property).
2. **Проверить и стабилизировать приложение.** Проверить реальные каналы, AirPlay, PiP, восстановление сети, длительный просмотр, доступность расписания, пустые состояния и отсутствие ложных кнопок просмотра. Серверы и ссылки должны работать для проверяющих и после публикации. Текущий временный хмарный архив и его конечный срок не подходят для обещания постоянного архива в App Store без дальнейшего решения. Карточки недоступных фильмов и незавершённые разделы нужно привести в соответствие с окончательно заявленными возможностями. [Требования к завершённости приложения](https://developer.apple.com/app-store/review/guidelines/#app-completeness).
3. **Вступить в Apple Developer Program.** Обычно 99 долларов США за год, окончательная цена зависит от региона. Владелец оформляет регистрацию и оплату самостоятельно в своём аккаунте. Для компании Apple запрашивает данные организации; для личного аккаунта продавцом выступает владелец. [Регистрация и цена](https://developer.apple.com/help/account/membership/program-enrollment).
4. **Создать запись приложения в App Store Connect.** Зарегистрировать Bundle ID, создать приложение, указать название VOLNA, основной язык, категорию, возрастной рейтинг, описание, скриншоты, адрес поддержки и публичную политику конфиденциальности. Правдиво заполнить App Privacy с учётом запросов к нашему API и сторонним видеосерверам. Privacy manifest в коде не заменяет эти ответы.
5. **Собрать релиз с подписью владельца.** Нынешний `UNSIGNED.ipa` предназначен для последующего личного переподписывания, он не является App Store-пакетом. Нужна релизная сборка с App Store-подписью и загрузка в App Store Connect. Сборку можно выполнять на собственном или облачном Mac; владелец сохраняет контроль над сертификатами и доступом. Текущий workflow такую подпись и загрузку не выполняет. [Подготовка приложения](https://developer.apple.com/documentation/Xcode/preparing-your-app-for-distribution).
6. **Проверить через TestFlight и отправить в App Review.** Пройти тестирование, заполнить сведения для проверки, при необходимости предоставить разрешения на контент, затем отправить приложение на рассмотрение. Само наличие оплаченного Developer-аккаунта не гарантирует одобрение. [Подача на проверку](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app).

В этой работе не создавались платные аккаунты, не выполнялись оплаты и подача приложения в App Store. Основной нерешённый вопрос для публичного онлайн-ТВ — подтверждённое разрешение на использование текущих сторонних потоков. Техническое наличие плеера и успешная личная установка этот вопрос не закрывают.
