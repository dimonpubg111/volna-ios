# VOLNA 2.2 для iPhone

Нативний застосунок SwiftUI + AVKit. Зимова версія з Liquid Glass, телепрограмою, власним плеєром, AirPlay та PiP.

[Зміни та встановлення](RELEASE-2.2.md). Складання й тести виконуються GitHub Actions на macOS. Готовий IPA з’являється у Releases тільки після успішного завершення перевірок; файл потребує підпису через Sideloadly.
