# Как получить настоящее приложение VOLNA на iPhone без собственного Mac

Подготовлен путь: **исходники → сборка на облачном Mac → IPA → подпись своей Apple Account с Windows → установка на iPhone**. Это нативное приложение, которое работает с собственным интерфейсом и видеоплеером. Safari и вход в ChatGPT для запуска приложения не нужны.

Сейчас в архиве находятся исходники, а не готовый IPA. Apple-компиляция и установка ещё не выполнены: на этом ПК нет Xcode, подключённого GitHub-аккаунта для запуска облачной сборки и вашего Apple-профиля для подписи. Дальнейшие шаги подготовлены, но их успешное выполнение на вашем iPhone пока не проверено.

## 1. Собрать приложение в облаке

1. В своём GitHub создайте отдельный репозиторий и загрузите в его корень содержимое папки `volna-ios`, включая `.github/workflows/ios.yml`. В исходниках нет паролей и ключей. Для бесплатных минут стандартного облачного macOS нужен публичный репозиторий; публикация кода будет доступна всем, поэтому решение о публичности остаётся за владельцем. Для приватного репозитория действуют квоты вашего аккаунта.
2. Откройте вкладку **Actions → VOLNA native iPhone → Run workflow**. Сценарий запускается вручную и ограничен 30 минутами.
3. Дождитесь зелёного результата сборки и тестов. При ошибке скачайте отчёт — он нужен для исправления, а не для установки неудачной сборки.
4. В разделе Artifacts скачайте `VOLNA-iPhone-native`. Внутри после успешной сборки будет файл **VOLNA-2.0-UNSIGNED.ipa**. Слово UNSIGNED означает, что он ещё не подписан и просто нажатием на iPhone не установится.

## 2. Подписать и установить с Windows

Для личного бесплатного тестирования можно использовать **AltStore Classic / AltServer**, сторонний инструмент с открытым исходным кодом. Он не входит в VOLNA и не устанавливался автоматически.

1. Следуйте [официальной инструкции AltServer для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Она описывает нужные версии iTunes/iCloud, установку AltServer, подключение iPhone и доверие компьютеру. Не заменяйте этот путь случайными сайтами с чужими сертификатами.
2. Установите AltStore Classic на iPhone через AltServer. Введите Apple Account только в локальном инструменте, если решите им воспользоваться. Пароль в чат или в исходники присылать не нужно.
3. Подключите iPhone к компьютеру. При необходимости включите Developer Mode и доверьтесь своему профилю в настройках iPhone.
4. Сохраните собранный IPA в «Файлы» на iPhone. В AltStore Classic откройте **My Apps → «+»** и выберите IPA. Для операции AltServer должен быть доступен с телефона по сети или кабелю.
5. После успешной подписи и установки откройте иконку **VOLNA**. Нужен iOS 17 или новее. Настоящее Liquid Glass доступно на iOS 26; на iOS 17–18 используется стеклянное оформление на системных материалах.

У бесплатного личного профиля срок **семь дней**. AltStore пытается продлевать его через AltServer; можно вручную нажимать **Refresh All**. Это не пожизненная установка: если профиль истечёт, приложение перестанет открываться до обновления. Лимит Apple — до трёх активных приложений такого типа, включая AltStore. [Описание сроков и ограничений](https://faq.altstore.io/altstore-classic/your-altstore).

Для обычной раздачи другим людям через TestFlight или App Store потребуется Apple Developer Program и подпись владельца. Случайные «вечные бесплатные сертификаты» в проект не добавлены.

## Что будет с каналами и фильмами

В приложении — настоящий каталог 155 украинских каналов, телепрограмма и доступные записи в том же окне просмотра. Состояние каждого потока зависит от поставщика. Реклама внутри самого видеопотока может оставаться.

Большой каталог популярных фильмов в собственном плеере ещё не подключён. Карточки, у которых есть только YouTube или недоступное прямое видео, помечены «Каталог» и не притворяются работающими фильмами. Подпись приложения сама по себе эту проблему не решает.
